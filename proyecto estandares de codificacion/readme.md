# Estándares de Codificación - Resumen de Sesiones

## Autor
**Miguel Arana Vásquez**

## Descripción

Este proyecto consiste en una página web desarrollada con el propósito de resumir los temas estudiados durante las primeras 11 sesiones del curso de **Estándares de Codificación**. En ella se presentan de forma organizada los conceptos más importantes, como la introducción a los estándares, herramientas de validación, nomenclatura, nombres descriptivos, diseño y programación, buenas prácticas, estructuras condicionales y repetitivas, manejo de excepciones, programación y modularización.

El objetivo del proyecto es facilitar el repaso de los contenidos del curso mediante una interfaz sencilla, organizada y de fácil navegación.
